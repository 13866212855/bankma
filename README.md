# 客户扫码提现 H5 全栈应用

客户扫码完成支付后自动触发提现/加款流程的全栈 H5 移动端应用。界面专为手机端适配优化，操作简洁，实时追踪提现进度，降低等待焦虑。

## 🌟 核心特性

- **管理后台系统 (`/admin`)**：
  - 访问 `/admin` 使用管理员账密 (`admin` / `admin123`) 登录；
  - 支持拖拽或选择二维码图片上传，通过 `jsQR` 本地解码自动识别并推送到前端；
  - 支持设置当前主推展示码、二维码列表管理与实时提现订单流控。
- **移动端极简交互**：专为 H5 手机竖屏（宽度 480px 弹性居中）优化，核心突出展示后台配置的二维码图片，直达支付与极速提现。
- **双模扫码识别**：
  - 支持 `getUserMedia` 调用设备后置摄像头实时毫秒级扫码；
  - 支持相册图片上传识别二维码（集成 `jsQR` 算法库）。
- **极速自动加款流程**：
  - 扫码即时解析商家名称、商品信息及应付金额；
  - 用户确认支付后，系统全自动发起加款申请，无需额外手动操作。
- **实时状态追踪与轮询**：
  - 步骤条时间轴展示（支付成功 ➔ 商家处理中 ➔ 加款处理中 ➔ 加款成功）；
  - 前端每 5 秒无感轮询后端，状态变更触发即时轻提示（Toast）；
  - 明确展示到账去向与脱敏账号（如：已转入您的微信账户 `wx_138****8000`）。
- **多收款渠道配置**：
  - 支持微信零钱、支付宝余额、银联银行卡三种渠道同时配置与切换默认到账方式。
- **企业级安全性**：
  - 数据库敏感账号采用 **AES-256-CBC** 密文加密存储；
  - 接口参数化 SQL 查询，杜绝注入漏洞；
  - 统一 API 返回格式 `{ code, message, data }` 与 Token 鉴权中间件。
- **预留三方出款扩展**：
  - `notify.js` 模块已预留标准微信支付 API v3 商家转账、支付宝单笔转账以及银联代付接口，自带仿真日志。

## 🗄️ 数据库设计 (PostgreSQL)

后端启动时会自动执行 `CREATE TABLE IF NOT EXISTS` 并自动写入演示商户码与测试用户：

1. **users**：用户基础表
2. **user_withdraw_config**：用户收款账户配置表（账号经 AES 加密）
3. **merchant_qrcodes**：商家收款码表（包含商户名、商品名、金额、QR 内容与图片）
4. **orders**：提现加款订单主表（包含流水号、支付状态、处理状态、提现渠道及各节点时间戳）
5. **order_logs**：订单操作流转审计日志表

## 🚀 本地快速启动步骤

### 1. 安装依赖
```bash
npm install
```

### 2. 启动全栈服务
```bash
node backend/server.js
```

服务启动后将输出：
```text
🎉 客户扫码提现 H5 应用服务启动成功!
🌐 访问地址: http://0.0.0.0:3000
📱 手机浏览器可通过本地局域网 IP 访问: http://[本机IP]:3000
```

### 3. 手机/浏览器访问与体验流程
1. 打开浏览器访问 `http://localhost:3000` 或手机访问局域网对应地址；
2. **扫码测试**：
   - 可在主页点击**「扫描二维码」**调用摄像头对准商户码；
   - 或点击**「上传二维码图片」**选择任意二维码图片解析；
   - 或在主页下方**「快捷演示商户码」**直接点击一键模拟扫码；
3. **确认支付**：
   - 弹窗确认商家、商品名称、金额及到账账户后，点击**「确认支付并自动提现」**；
4. **进度追踪**：
   - 系统自动跳转至**订单状态页**，以时间轴形式展示 `支付成功 ➔ 商家处理中 ➔ 加款处理中 ➔ 加款成功`；
   - 页面每 5 秒无感轮询更新，加款成功后顶部弹出 Toast 并提示资金到账去向。

## 🔌 生产第三方出款接入指南 (`notify.js`)

- **微信支付商家转账到零钱**：
  - 调用微信 API v3: `POST https://api.mch.weixin.qq.com/v3/transfer/batches`
  - 填入微信商户号 (`mchid`)、商户证书与私钥 (`apiclient_key.pem`) 及 APIv3 密钥。
- **支付宝单笔转账到支付宝账户**：
  - 引入 SDK 调用接口: `alipay.fund.trans.uni.transfer`
  - 填入应用私钥与支付宝公钥即可直接完成原路出款。
